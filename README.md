# liamz-skills

Index of six independent Claude skills. Each lives in its own repository and works on its own; install only the ones you want.

| Skill | What it does |
| --- | --- |
| [`decision-making`](https://github.com/liamzmind/decision-making) | A six-phase method for big decisions, with a review that separates a bad decision from bad luck. |
| [`dev-rules`](https://github.com/liamzmind/dev-rules) | Working rules for AI-assisted projects: clarify first, stay in scope, verify, report honestly, define done. |
| [`code-audit`](https://github.com/liamzmind/code-audit) | A read-only, evidence-based codebase audit ranked by severity, with path:line evidence. |
| [`release-close`](https://github.com/liamzmind/release-close) | Gated audit-then-close for Android and iOS releases. Never uploads or submits without a separate request. v0.1. |
| [`ai-butler`](https://github.com/liamzmind/ai-butler) | A composed, candid, dry-witted chat voice. Conversation only. |
| [`yt-synthesis`](https://github.com/liamzmind/yt-synthesis) | Source-linked synthesis of a YouTube channel's most viewed and most relevant recent videos. v0.1. |

Each repo's README has install steps. All are MIT licensed.
